# Nhat Minh Doan — citation evidence dashboard

This repository hosts a citation-audit application for the mathematical publications of Nhat Minh Doan. It will collect bibliography evidence from scholarly metadata indexes and public preprint archives, deduplicate citing-paper versions, and report a verified lower bound alongside candidate citation links.

The website is published from `docs/`. The audit program and its data are versioned in this repository. Google Scholar and ResearchGate totals are not treated as ground truth.

**Status:** setup in progress. Do not treat the initial seed data as a complete citation census.
